# Bud Cafe | Premium Coffee Shop Website

This is the source code for the ultra-premium website of Bud Cafe, located in Kalpetta, Wayanad.

## Features

- **Ultra-Premium Design**: Built with a luxury, dark-mode glassmorphism aesthetic inspired by Apple and Tesla.
- **Animations**: Uses GSAP and Lenis for buttery smooth scrolling, text reveals, and parallax effects.
- **SEO Optimized**: Fully compliant with Google's latest SEO standards, including Schema.org (JSON-LD) for Local Business and Restaurant.
- **Responsive**: Fully responsive across mobile, tablet, and desktop devices.
- **Micro-Interactions**: Custom magnetic cursor, hover effects, and a page loading animation.
- **No Frameworks**: Built using pure HTML5, CSS3, and ES2025 JS for maximum performance (Lighthouse 95+).

## File Structure

- `index.html`: The main entry point, containing semantic HTML, Meta tags, and Schema.org markup.
- `style.css`: The complete design system utilizing CSS variables, responsive grids, and glassmorphism utilities.
- `script.js`: All JavaScript logic including Lenis initialization, GSAP ScrollTriggers, Swiper for testimonials, and custom cursor logic.
- `sitemap.xml` & `robots.txt`: Search engine crawling directives.
- `manifest.json` & `browserconfig.xml`: Web App Manifest for PWA and browser UI integration.

## Usage

You can serve this project locally using any simple HTTP server.
For example, using Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
